# 轨道座体与园林铸件化验复盘

化验结果和料批均为模拟数据。每炉每元素至少两家化验台复测，对化验台分别取中位数后计算台间极差。单据只在炉前化验事件和抵达日期均可见时生效，旧修订无法覆盖新单。材料证书生效期采用半开区间，料批牌号不一致则停用整炉。

历史输入中的成分为质量百分比，温度为设备读数，料批 `mass_kg` 为称重公斤。按照挂牌产品和成分字段分层，严格以终检报告首次可见日分开建模与回放。模型拟合炉前化验到终检的稳健残差，中位数及绝对离差设定特征尺度。残差绝对分位加上双化验极差的一半用于区间，超出历史支持范围挂起质检。

纠偏额度为模拟台架单位，表示检验工位可在当班处理的调校点数。使用该工位约定的步进向上对齐需求量，同时向下对齐已验证的安全空间及当班容量。批准只进入复验状态。交割看终检成分、复验实际消耗和完整元素覆盖。

整炉预留按牌号配对同一炉次各应验元素的滚动终检残差；校准时只能见到使用日之前已发布的终检，迟到记录在发布后才进入样本，缺少任一应验元素的炉次不参与校准。候选补料量仍按原称量步进和单元素限额枚举，只有补料后全部应验元素同时落在牌号区间内才算该炉命中；完整样本数不足或置信距离超出历史支持范围时整炉挂起。满足原经验置信要求的候选中取总台架单位最少者。当班容量不能容纳该整炉方案时，该炉进入整炉排队，各元素预留均为零；交割继续按元素预留、实际称量和完整覆盖核验。

## 量具判断、签发凭证与班组放行

复测按照炉次、元素、台位和复测号分组，不同单据使用同一个复测位时先隔离冲突。台内离差按自由度合并，台间差异用各台中位数的极差。两种风险各自挂起，不用一个较好结果抵消另一个。

称量追踪与供应方签发件分开对账。证书需按发布日期及当前修订可见，料批号、牌号及活动区间同时吻合。证书撤销后所涉物料列为挂起并汇总重量。炉次模型附最近业务日的前推绝对误差对照，每次回放只能见到当时已发布的往期终检。班末按牌号应验元素逐炉统计待验项目、交割状态和台架预留、使用、剩余。
